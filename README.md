# Accounts Service

![Build Status](https://github.com/Devyani-Patil2/ci-cd-final-project/actions/workflows/ci-build.yaml/badge.svg)

A RESTful service for managing customer accounts.

## Project Overview

This project implements REST API operations to create, read, list, update, and delete customer accounts.
